# Premium Payment Archive

Premium membership and payment integration is intentionally archived for the current release.

- The frontend does not expose Buy Premium or payment actions.
- No payment gateway is active in the app.
- Supabase billing/UPI schema may remain deployed as backend infrastructure for a later release.
- Premium plan metadata is not hard-coded in the client.
- Re-enable only after the backend verification, entitlement, refund/cancellation, and UPI reconciliation contracts are production-ready.
