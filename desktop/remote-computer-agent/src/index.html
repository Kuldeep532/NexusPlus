Security

Unlock and remote-control requests require a fresh challenge signed by the paired phone's authentication-bound device key after phone biometric authentication. This agent never receives the phone's private key or OS password.

Keyboard shortcuts

  • Ctrl+Space: mute or unmute microphone
  • Ctrl+Shift+V: toggle meeting video
  • F6: move focus to agent status
  • F8: toggle voice input
  • Ctrl+F10: lock computer

Accessibility

The agent advertises NVDA, Orca, or VoiceOver capability to the phone. Native accessibility helpers are required for operations that are not available through standard desktop APIs.
